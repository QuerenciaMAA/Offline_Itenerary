Daily itinerary - offline app

Quick use (no setup): open index.html in Chrome. It works with no internet.

Install as an app (recommended on Android):
1. Upload this whole folder to a free static host once (GitHub Pages, or drag the folder onto app.netlify.com/drop).
2. Open the link in Chrome on your phone while online.
3. Chrome menu > "Add to Home screen" / "Install app".
After that it opens from your home screen with no internet. Your changes are saved on that phone.
